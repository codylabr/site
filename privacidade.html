Política de privacidade

Como a Codyla trata os dados do site e do sistema Codyla Folgas.

Esta política segue a Lei Geral de Proteção de Dados (Lei nº 13.709/2018, LGPD). Ela tem duas partes: os dados enviados pelo site codyla.com.br e os dados guardados no sistema Codyla Folgas.

O site e o sistema são oferecidos por Flávio Barbosa Louseiro Lima, sob o nome comercial Codyla. Contato: contato.codyla@gmail.com.

Parte 1: o site

Quais dados coletamos. Só os que você preenche no formulário de contato: nome, e-mail, WhatsApp, empresa, CNPJ, número de funcionários e a mensagem.

Para que usamos. Para responder ao seu contato e, quando esse for o assunto, combinar o teste do Codyla Folgas. Não vendemos nem compartilhamos seus dados para fins de marketing.

Onde ficam. As mensagens são enviadas ao e-mail da Codyla pelo serviço FormSubmit, usado só para esse fim.

Parte 2: o sistema Codyla Folgas

Na LGPD, a empresa cliente é a controladora dos dados dos funcionários dela: ela decide o que cadastrar e para quê. A Codyla é a operadora: guarda e processa esses dados só para prestar o serviço e só conforme as instruções do cliente.

O sistema não pede dados sensíveis, como saúde, religião ou filiação sindical. O cliente não deve escrevê-los em campos livres, como o motivo de uma licença.

Com quem os dados são compartilhados

Com ninguém para fins de marketing. Só com os serviços necessários para o sistema funcionar: o servidor (Hostinger, com dados guardados no Brasil), o envio de e-mail (Google) e a cobrança (Asaas). Ou quando a lei ou uma ordem judicial exigir.

Segurança

  • Senhas guardadas com criptografia (BCrypt), nunca em texto.
  • Bloqueio depois de 5 senhas erradas e limite de tentativas por endereço de internet.
  • Verificação em duas etapas, obrigatória no acesso de administração da Codyla.
  • Separação por empresa em toda consulta, conferida por testes automáticos.
  • Conexão criptografada (HTTPS) e cópia de segurança diária.

Por quanto tempo

Enquanto o contrato durar. Depois do cancelamento, o cliente tem 30 dias para pedir a exportação dos dados. Passado esse prazo, os dados são apagados em até 60 dias, e das cópias de segurança em até 90 dias. Ficam só os dados que a lei obriga a guardar, como os de cobrança.

Incidentes

Se houver um incidente de segurança que possa afetar os dados, a Codyla avisa o cliente em até 48 horas depois de tomar conhecimento, com o que aconteceu e o que foi feito. Assim o cliente consegue cumprir o prazo de comunicação à ANPD.

Seus direitos

Você pode pedir a qualquer momento para consultar, corrigir ou apagar os seus dados enviados pelo site, pela página de contato.

O funcionário de uma empresa cliente que quiser consultar, corrigir ou apagar os próprios dados deve falar com a empresa onde trabalha, que é a controladora. A Codyla ajuda o cliente a atender esses pedidos. O próprio usuário corrige os dados dele em Minha Conta.
